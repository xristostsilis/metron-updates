# Metron — λήψη & ενημερώσεις

Αναλυτής FM/MPX για ραδιοφωνικούς σταθμούς. Από εδώ κατεβαίνει η εφαρμογή, και από εδώ ελέγχει η ίδια για νέες εκδόσεις.

## Windows

[**Λήψη Metron.exe**](https://github.com/xristostsilis/metron-updates/raw/main/windows/Metron.exe)

1. Αποθηκεύστε το `Metron.exe` σε έναν φάκελο, π.χ. `Επιφάνεια εργασίας\Metron`, και ανοίξτε το. Δεν χρειάζεται εγκατάσταση.
2. Αν εμφανιστεί η μπλε προειδοποίηση των Windows, επιλέξτε «Περισσότερες πληροφορίες» → «Εκτέλεση».
3. Για RTL-SDR (V3 ή V4) χρειάζεται ο οδηγός WinUSB μέσω Zadig, όπως για SDR# ή MPXtool.

Απαιτεί Windows 10 ή 11 (64-bit).

## Ενημερώσεις

- Το Metron ελέγχει για νέα έκδοση λίγο μετά το άνοιγμα και κάθε 6 ώρες. Ο αυτόματος έλεγχος απενεργοποιείται από **Ρυθμίσεις → Σύστημα → Ενημερώσεις**.
- Όταν βρει νέα έκδοση, δείχνει τι νέο υπάρχει και **ρωτά πριν την εγκαταστήσει**. Ο έλεγχος γίνεται και χειροκίνητα με το «Έλεγχος τώρα».
- Κάθε έκδοση είναι ψηφιακά υπογεγραμμένη (Ed25519). Το Metron δεν εγκαθιστά αρχείο χωρίς σωστή υπογραφή.
- Η εγκατάσταση παίρνει λίγα δευτερόλεπτα. Μετά το Metron ανοίγει ξανά μόνο του, με τις ρυθμίσεις του.
